# 04. Систематическая отладка

**Источник:** Superpowers (systematic-debugging).

## Идея

Не чинить «наугад». Рецепт по шагам: симптом дословно → воспроизведение → локализация (с границами разведки) → гипотезы → класс причины → минимальное исправление в слое причины → попытка опровергнуть собственное исправление → как подтвердить. Исправление сначала предлагается, вносится после согласия человека.

## Что внутри

| Файл | Назначение |
|---|---|
| `.workmate/skills/sistemnaya-otladka/SKILL.md` | навык «Систематическая отладка» (v2); срабатывает сам, когда в запросе ошибка, исключение, падающий тест, «не работает» |
| `.workmate/commands/отладить.md` | `/отладить <симптом>` — шаги 1–5, предложение исправления, **остановка до правки**, исправление только после подтверждения |

**Уровень установки:** любой (рекомендуется общий или рабочая область).

## Как пользоваться

`/отладить <текст ошибки или описание неверного поведения>` → прочитайте разбор (симптом, воспроизведение, причина с доказательством, предлагаемое исправление) → подтвердите → агент вносит правку и говорит, как ее проверить → **запустите тесты сами**.

## Что показал эксперимент

Три дефекта, без навыка и с навыком:

| | Без навыка | `/отладить` |
|---|---|---|
| Причина найдена | 3/3 | 3/3 |
| Регрессии в исправлении | 1 | 1 (в v1) |
| Остановка до правки | 1/3 | 3/3 |
| Честное «не подтверждено прогоном» | 0/3 | 3/3 |

- Навык не ускоряет поиск причины — агент и так ее находит. Он дает дисциплину и проверяемый разбор, по которому человек быстро ловит регрессию.
- v2 (добавлены «Границы разведки» и «Попробуй опровергнуть исправление») на дефекте, где v1 внес регрессию, сразу дал верное исправление без подсказки — вдвое быстрее и с вдвое меньшим расходом контекста.

## Ограничения

- Качество исправления по-прежнему надо проверять: агент не запускает тесты.
- Выводы — по трем дефектам одной конфигурации.
